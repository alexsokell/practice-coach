Connecting

Piano / keyboard and drums / e-kit: plug in by USB (or a Bluetooth MIDI adapter), press Connect input, allow MIDI. No keyboard? Piano works from your computer keys (A W S E D F T G Y H U J K = C4 to C5), drums from A = kick, S = snare, D = hi-hat.

Guitar, bass, voice: press Connect input and allow the microphone. Play one note at a time (single notes, not chords). An audio interface or a clip-on pickup works best; a laptop mic works for a quiet room. Mic instruments are graded on the note name, so the octave doesn't count against you.

Form check: turns on your webcam and tracks your hands. It flags flat fingers and a dropping wrist. It's rough and experimental.

Simulate a run fakes a slightly sloppy performance so you can see the scoring without an instrument.

If MIDI or the mic won't connect when opening the file directly, open Terminal in this folder and run python3 -m http.server 8000, then go to http://localhost:8000 in Chrome.
